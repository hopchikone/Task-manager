# Приложение «Задания» — установка на Android

## Что скачать

| Файл | Что это |
|---|---|
| **`Zadaniya-1.1.apk`** | Настоящее Android-приложение (82 КБ). Системные push-уведомления о дедлайнах работают **даже при полностью закрытом приложении**. |
| `Дневник-заданий.html` | Та же логика в виде одного веб-файла, если APK ставить не хочется (уведомления тогда работают только при открытом приложении). |

## Как установить APK

1. Скачайте `Zadaniya-1.1.apk` на телефон (кабель, Telegram «Избранное», Google Диск, почта).
2. Откройте файл в проводнике телефона.
3. Android спросит разрешение «Устанавливать из этого источника» — разрешите для приложения,
   из которого открываете файл (Файлы / Chrome / Telegram). Это стандартное требование для
   установки не из Google Play.
4. Нажмите «Установить» → «Открыть». На рабочем столе появится иконка **Задания**.

Приложение занимает 82 КБ, работает офлайн, не требует интернета и ничего не отправляет в сеть.

## Уведомления: что разрешить один раз

После первого запуска:
1. Android может спросить разрешение на уведомления — нажмите **Разрешить**.
2. В приложении: иконка 🔔 (колокольчик) → включите «Уведомления о дедлайнах»,
   выберите **время** (например 09:00) и **за сколько дней** напоминать (0–3).
3. Кнопка «Проверить уведомление» покажет тестовое уведомление сразу.

Если уведомления не приходят:
- Настройки Android → Приложения → **Задания** → Уведомления → разрешить, канал «Дедлайны».
- Настройки Android → Приложения → **Задания** → «Будильники и напоминания» (Android 12+) → разрешить —
  это нужно, чтобы телефон не задерживал напоминание в режиме экономии энергии.
- Некоторые прошивки (Xiaomi, Realme, Samsung) дополнительно «усыпляют» приложения:
  настройки батареи → «Без ограничений» для приложения «Задания».

## Как это устроено

- Интерфейс — тот же самый офлайн-дневник (задания, предметы, приоритеты, заметки,
  поиск, календарь, расписание с синей и красной неделей).
- Напоминания ставятся системным `AlarmManager` (точные будильники, режим Doze учитывается):
  уведомление приходит в выбранное время за N дней до срока сдачи.
- После перезагрузки телефона напоминания перепланируются автоматически (`BootReceiver`).
- Задания и расписание сохраняются в файл приложения и подхватываются при запуске.
- Интернет не используется: приложение не имеет разрешения на сеть.

## Исходники

Папка `android-build/` — полный проект (Java, Gradle, без сторонних библиотек):

```
android-build/
├── build.gradle, settings.gradle, gradle.properties
├── local.properties           путь к Android SDK
├── build_apk.sh               сборка: bash build_apk.sh
├── keystore.jks               ключ подписи (пароль zadaniya123, alias zadaniya)
├── setup_sdk.sh               установка JDK 17 и Android SDK
└── src/main/
    ├── AndroidManifest.xml
    ├── assets/www/            веб-приложение (index.html, style.css, app.js)
    ├── java/com/arena/zadaniya/
    │   ├── MainActivity.java      WebView + мост JS↔Android
    │   ├── NativeStore.java       хранилище + AlarmManager
    │   ├── ReminderReceiver.java  показ уведомления
    │   └── BootReceiver.java      перепланирование после перезагрузки
    └── res/                   иконки, тема, строки
```

Пересобрать: `bash android-build/build_apk.sh` (нужны JDK 17 и Android SDK 34).
Для публикации в Google Play нужен `.aab` и собственный ключ подписи:
`./gradlew bundleRelease` с вашим keystore.
