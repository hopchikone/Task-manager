# История версий

## 1.1 — 23 ноября 2026
- Синяя и красная недели в расписании: урок бывает «каждую неделю», «только синяя» или «только красная».
- Переключатель недели с датами (Пн–Вс), подсказка, если в этот день уроки только в другой неделе.
- В настройках можно указать, какой цвет недели идёт сейчас — дальше чередование идёт само.
- Нативные напоминания Android: точные будильники, канал «Дедлайны», перепланирование после перезагрузки.
- Резервная копия данных: экспорт и импорт `.json`.

## 1.0 — 23 ноября 2026
- Задания по предметам с дедлайнами, важностью и заметками.
- Поиск, фильтры, счётчики, календарь с отметками по дням.
- Расписание уроков со связкой заданий по предмету.
- Первая сборка APK.
