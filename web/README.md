# Дневник заданий — приложение для учёбы (тёмная тема)

Приложение для Android (и любого устройства с браузером): задания по предметам,
дедлайны, важность, заметки, поиск, фильтры и ежедневник с календарём.
Работает **полностью офлайн**, данные хранятся только на вашем устройстве.

## Два варианта файлов

| Файл | Что это |
|---|---|
| **`Zadaniya-1.1.apk`** | Android-приложение с настоящими системными push-уведомлениями (работают при закрытом приложении). Инструкция — в `УСТАНОВКА-APK.md`. |
| **`Дневник-заданий.html`** (в корне рабочей папки) | Всё в одном файле: стили, код, иконка. Можно скачать на телефон и открыть в браузере. Самый простой вариант. |
| **`study-planner/`** | Полный проект для размещения в интернете (PWA): `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `sw.js`, иконки. Позволяет установить приложение «по-настоящему» с иконкой и запуском без адресной строки. |

## Как установить на Android

**Вариант 1 (быстро, из файла)**
1. Скачайте `Дневник-заданий.html` и откройте файл в Chrome.
2. Меню Chrome ⋮ → «Добавить на главный экран».
3. Запускайте с иконки — приложение откроется на весь экран.

**Вариант 2 (полноценная установка PWA, нужен любой хостинг)**
1. Загрузите все файлы из папки `study-planner/` в любую бесплатную статику:
   GitHub Pages, Netlify Drop, Cloudflare Pages, Vercel.
2. Откройте ссылку на телефоне в Chrome.
3. Меню ⋮ → «Установить приложение». Появится иконка в списке приложений,
   запуск без браузерной обвязки, офлайн-режим через service worker.

> Данные хранятся в localStorage браузера, поэтому приложение лучше держать
> на одном устройстве и не чистить данные сайта. Для варианта 1 держите файл
> на одном и том же пути — Chrome привязывает хранилище к адресу файла.

- **`Дневник-заданий.html`** — единственный файл, который нужен на телефоне.
  Скопируйте его на Android (кабель, Telegram «Избранное», Google Диск, почта),
  откройте в Chrome → меню ⋮ → «Добавить на главный экран». Приложение работает офлайн.

> Про формат `.app`: Android не запускает файлы `.app` — это формат приложений macOS,
> а на Android приложения ставятся из `.apk`/`.aab` или как PWA с главного экрана.
> Поэтому приложение отдаётся единым HTML-файлом: он открывается в браузере телефона
> и ставится иконкой на рабочий стол, как обычное приложение.

## Что умеет

- **Задания**: название, предмет, срок сдачи (дата), заметка.
- **Важность**: низкая / средняя / высокая — цветная полоса на карточке.
- **Список**: группировка по датам (просроченные → сегодня → дальше → выполненные),
  бейджи «сегодня», «просрочено», «завтра», счётчик заданий.
- **Счётчики сверху** — нажмите, чтобы отфильтровать: просрочено / на неделе / выполнено.
- **Поиск** по названию, предмету и заметкам.
- **Фильтры**: все / активные / просроченные / выполненные + фильтр по предмету
  одним нажатием на метку предмета.
- **Выполнение**: отметка галочкой, с отменой через всплывающее сообщение.
- **Календарь**: точки на днях (цвет = важность, серый = всё выполнено),
  выбор дня и список заданий на этот день, кнопка «+ добавить» на выбранную дату,
  переход по месяцам, тап по названию месяца — возврат к текущему месяцу.
- **Расписание уроков**: уроки по дням недели с временем и кабинетом, кнопка «+ урок»
  на экране расписания. Связано с заданиями по названию предмета: задания по математике
  автоматически показываются внутри урока «Математика» с отметкой срока сдачи и галочкой
  (отметка синхронизируется с общим списком). Текущий урок подсвечивается меткой «сейчас».
- **Синяя и красная недели**: вкладка «Расписание» показывает неделю целиком
  (Пн–Вс с датами) и переключается между синей и красной — видны уроки именно той недели.
  У каждого урока есть признак «Каждая / Синяя / Красная», поэтому, например, физика
  может стоять только по синей неделе, а химия — только по красной. Чередование считается
  автоматически от опорной даты; в настройках можно указать, какая неделя идёт сейчас,
  если цвета не совпадают со школьным дневником (дальше чередование продолжится само).
  На карточке урока показана метка «синяя»/«красная», а в пустой день подсказка:
  «В красную неделю здесь 2 урока — переключите неделю сверху».
- **Напоминания о дедлайнах**: иконка колокольчика → время (например, 09:00) и за сколько
  дней напоминать (0–3). Приходит системное уведомление «Скоро дедлайн» со списком задания,
  плюс баннер на главном экране при запуске. Кнопка «Проверить уведомление» для теста.
  Настройки сохраняются на устройстве.
- **Резервная копия**: скачивание и загрузка файла `.json` со всеми заданиями, уроками
  и настройками — перенос на новый телефон без потери данных.
- **Удаление** с кнопкой «Вернуть» в течение нескольких секунд.
- **Автосохранение** при любом изменении. Тёмная тема, адаптив под телефон.

## Структура проекта

```
study-planner/
├── index.html            разметка (главный экран + календарь + форма задания)
├── style.css             тёмная тема, адаптивная вёрстка, безопасные зоны Android
├── app.js                логика: хранилище, рендер, календарь, расписание, напоминания
├── manifest.webmanifest  описание PWA (иконки, тема, standalone-режим)
├── sw.js                 офлайн-кэш
├── icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
└── build_single.py       пересборка единого файла: python3 build_single.py
```

Если меняете `index.html`, `style.css` или `app.js` — запустите
`python3 build_single.py`, чтобы обновить версию «всё в одном файле».

## Уведомления: браузер против APK

- **В APK** (`Zadaniya-1.1.apk`) напоминания системные: `AlarmManager` + канал уведомлений
  Android, точное время, работают при закрытом приложении и после перезагрузки телефона.
- **В HTML-версии** уведомление показывается, только пока приложение открыто или недавно
  свёрнуто (браузер усыпляет фоновые вкладки), плюс баннер «Просрочено» при запуске.
  Обе версии используют один и тот же код интерфейса; при запуске внутри APK
  приложение автоматически переключается на нативные напоминания.

## Возможные доработки

- Полноценные push-уведомления при закрытом приложении (нужна .apk-сборка).
- Экспорт в CSV/календарь (.ics).
- Несколько профилей/семестров, вторая неделя расписания (числитель/знаменатель).
- Синхронизация между устройствами.
